MANUL KOMBAT 2.3.3 — СБОРКА WINDOWS

В проекте настроена сборка двух вариантов приложения:
1) обычный установщик NSIS;
2) portable-версия без установки.

СБОРКА
1. Установи Node.js LTS с https://nodejs.org/.
2. Распакуй весь архив в отдельную папку.
3. Запусти build_exe_windows.bat.
4. Дождись окончания npm install и electron-builder.
5. Готовые файлы появятся в папке dist. Названия файлов смотри в выводе сборщика.

Первая сборка требует интернет для загрузки Electron и зависимостей.
Для сборки Windows EXE рекомендуется выполнять сборку на Windows. В этой среде EXE не собран и не проверен.

Важно: приложение не подписано цифровым сертификатом издателя, поэтому Windows SmartScreen может показать предупреждение. Это не подтверждает ни безопасность, ни вредоносность файла — проверяй источник и подпись самостоятельно.

Сохранения Electron хранятся отдельно от Chrome/Edge. Для переноса прогресса используй встроенные кнопки экспорта и импорта сохранения.
