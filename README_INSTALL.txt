MANUL KOMBAT 2.3.3 — ИНСТРУКЦИЯ

БЫСТРЫЙ ЗАПУСК В БРАУЗЕРЕ
1. Распакуй архив полностью.
2. Открой index.html в современном браузере.
3. Для PWA-установки и офлайн-кеша запускай игру через HTTPS или localhost.

ЗАПУСК В WINDOWS КАК ОТДЕЛЬНОЕ ПРИЛОЖЕНИЕ
1. Установи Node.js LTS.
2. Открой папку проекта в PowerShell или CMD.
3. Выполни npm install, затем npm start.
4. Для создания установщика и portable EXE запусти build_exe_windows.bat.

СОХРАНЕНИЯ
Прогресс хранится локально в профиле браузера или Electron. Используй «Экспорт сохранения» перед переносом на другое устройство. Не удаляй JSON-файл, пока не убедишься, что импорт прошёл успешно.

РЕКЛАМА
Рекламные награды доступны только при запуске внутри VK Mini Apps и при наличии доступного рекламного инвентаря. В обычном браузере/настольной версии реклама не симулируется.
