MANUL KOMBAT 2.0

Распакуйте все 5 файлов в одну папку игры с заменой старых файлов. Не удаляйте папку assets и резервные копии. Запуск: python -m http.server 8000, затем открыть http://localhost:8000.

Изменения: новая арена и интерфейс, 4 оригинальных скина, сбалансированная экономика, лимит бонусной рекламы 3 раза в день, задания, босс, сезонный пропуск, профиль и 32 достижения. Сохранение существующего баланса/уровней; пассивный доход пересчитывается по правилу 1 монета/сек на ферму. Монеты не являются реальными рублями.
