# MANUL KOMBAT 2.3.3 — пакет проекта для потенциального покупателя

## Краткое описание
MANUL KOMBAT — одиночная idle-clicker RPG в браузере и настольном окне Electron. Игрок развивает манула кликами, покупает улучшения и фермы, проходит эволюцию, сражается со Стражем арены, открывает облики, выполняет ежедневные задания, получает достижения и награды боевого пропуска.

## Что входит в пакет
- Полный клиентский исходный код HTML/CSS/JavaScript.
- Игровая логика, локальные сохранения и перенос прогресса через JSON.
- Система эволюции, комбо, улучшений и пассивного дохода.
- Босс, кристаллы, облики, перерождение, задания и боевой пропуск.
- 32 достижения.
- Анимации персонажа и эффекты покупок.
- PWA-манифест и service worker для офлайн-кеша при размещении на HTTPS/localhost.
- Конфигурация Electron и Windows-сборки NSIS/portable.
- SVG-иконка и Windows ICO.

## Быстрый запуск
Открой `index.html` в современном браузере. Для настольного приложения установи Node.js LTS, выполни `npm install`, затем `npm start`. Для сборки Windows установщика выполни `build_exe_windows.bat` на Windows.

## Технические требования
- Современный Chromium-браузер (Chrome/Edge) или совместимый браузер.
- Node.js LTS для Electron-запуска и сборки.
- Интернет нужен для первоначальной установки npm-зависимостей и VK Bridge/рекламных функций. Базовая одиночная игра рассчитана на локальный запуск; PWA-кеш работает на HTTPS/localhost.

## Сохранения
Игра использует localStorage. Сохранение относится к конкретному браузерному профилю/установке Electron. Встроенный экспорт/импорт переносит игровой прогресс между устройствами.

## Монетизация и онлайн-функции
В проекте есть интеграция с VK Bridge для рекламных форматов. Она зависит от запуска внутри VK Mini Apps и доступности рекламы. Платежи за реальные деньги, серверная авторизация, облачная синхронизация и мультиплеер не реализованы. Не рекламировать их как готовые функции.

## Состояние проверки
Синтаксис всех JavaScript-файлов проверен через `node --check`; целостность исходного ZIP проверена; выполнен статический осмотр файлов и исправлены обнаруженные несоответствия. Полноценное ручное тестирование на Windows, телефонах, в VK Mini Apps и тестирование экономики с длительными игровыми сессиями ещё требуется. Windows EXE в этой среде не собран.
